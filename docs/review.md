# 홈페이지 수정 검토 의견

## 수정 요청 1: 메인 페이지 추천 메뉴 랜덤·순차 표시

- 페이지 또는 파일: 메인 페이지 (`index.html`), 메뉴 표시 로직 (`app.js`)
- 위치/요소: 메인 페이지의 `추천 메뉴` 영역
- 현재 상태: 추천 메뉴가 고정된 항목으로 표시되어, 페이지를 다시 열어도 메뉴 구성이 바뀌지 않습니다.
- 원하는 수정 사항:
  1. 메인 페이지의 추천 메뉴 영역에 전체 메뉴 중 무작위로 선정한 메뉴 12개를 표시해 주세요.
  2. 선택된 12개 메뉴가 한꺼번에 나타나지 않고, 각 메뉴 카드가 차례대로 애니메이션을 적용받으며 출력되도록 해 주세요.
  3. `index.html`을 새로 열거나 새로고침할 때마다 무작위 메뉴를 다시 선정해 추천 구성이 갱신되도록 해 주세요.
  4. 한 번의 페이지 진입에서 동일 메뉴가 중복 선정되지 않도록 해 주세요.
- 우선순위: 높음
- 완료 확인 기준: 페이지를 다시 열 때 추천 메뉴가 새로 선정되고, 총 12개 카드가 순차적으로 애니메이션 표시되는지 확인합니다.

## 기타 의견

- 메뉴명과 사진은 `menu.md`에 정리된 메뉴 데이터를 기준으로 사용해 주세요.

## 수정 요청 2: 첫 화면 인사말 및 랜덤 커피 이미지

- 페이지 또는 파일: 메인 페이지 (`index.html`), 메인 화면 동작 (`app.js`)
- 위치/요소: 첫 화면 히어로의 메인 문구와 두 잔의 커피 이미지
- 현재 상태: 첫 화면에 `커피를 커피답게` 문구와 고정된 커피 이미지 두 장이 표시됩니다.
- 원하는 수정 사항:
  1. 첫 화면의 `커피를 커피답게` 문구를 `안녕하세요. 컴포즈커피입니다.`로 변경해 주세요.
  2. 첫 화면에 표시되는 커피 이미지 두 장을 메뉴 자료의 제품 사진 중 무작위로 선택해 주세요.
  3. 두 이미지는 서로 다른 사진이어야 하며, 메인 페이지를 열거나 새로고침할 때마다 새로 선택해 주세요.
- 우선순위: 높음
- 완료 확인 기준: 첫 화면에 새 인사말이 표시되고, 매 진입 때 서로 다른 두 메뉴 사진이 선택되는지 확인합니다.
